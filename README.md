Vice City Cover Maker — an offline web app that turns your photos and a
caption into GTA 6-style multi-panel cover art: one big hero panel, two
stacked panels, a sunset caption band with bold lettering, three colour
grades (Sunset, Neon Night, Vice Pink) and the common post sizes
1080 x 1080, 1080 x 1350 and 1920 x 1080. Drag a photo to crop it, scroll
to zoom, export the cover as a PNG.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Everything runs
offline: photos stay on your machine, no network requests.
